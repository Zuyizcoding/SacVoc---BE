## Regression coverage

- Missing reference/prediction no longer produces accuracy 1.0.
- Missing outputs remain misses; optional unlabeled sub-season metrics are null.
- Duplicate, unknown, malformed and mismatched legacy rows fail explicitly.
- Direct-script and module CLI forms preserve their public arguments/report keys.
- Reviewer forms start blank and omit model scores, confidence, bias tags/vectors.
- Different reviewer orders are joined by task identity; context stays immutable.
- Blank/fractional grades, missing/extra/duplicate tasks and wrong identities fail.
- Disagreements create no partial exporter request and no automatic average.
- Every explicit resolution needs a valid grade and a non-empty reason.
- Catalog changes after annotation block export of stale judgments.
- HTML escapes catalog text; disallowed link schemes are omitted; spreadsheet
  display text is kept literal when necessary.
- Docker tests use only freshly created, uniquely named containers and volumes,
  verify non-root operation and persistence, and remove only those resources.
- No user history, real annotation, Gemini request or model encoder was used.
